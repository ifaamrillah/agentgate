# M0 Fondasi Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fondasi repo Agent Gate: Cargo workspace, dev full-Docker, skeleton Loco dengan frontend ter-vendor, keamanan web dasar, CI, modul Worktree, dan tiga spike tertulis.

**Architecture:** Cargo workspace dengan empat crate (`server` = aplikasi Loco, `cli` = binary `agentgate`, `core`, `graph`). Semua toolchain berjalan di container `app`; `bin/*` di host meneruskan perintah ke container. Postgres/MinIO/Mailpit berada di satu Compose project bersama; setiap checkout/worktree punya container `app` sendiri.

**Tech Stack:** Rust 1.99.1 (edition 2024), Loco 1.3.1, SeaORM 2.0.x, Tera 2, fluent-templates 0.15, HTMX 4.0.1 + hx-preload, Basecoat 1.1.0, Tailwind 4.3.5 standalone, Tabler Icons 3.51.0, Postgres 18 + pgvector, MinIO, Mailpit.

**Spec:** `docs/spec.md` (bagian "Arsitektur & tech stack", "Repo, hosting & distribusi", "Urutan build MVP" baris M0) dan konvensi `docs/reference/loco-project-rules.md` (§1–3, §6, §9–11, §14). Desain cara kerja: `docs/superpowers/specs/2026-11-11-agentgate-build-design.md`.

## Global Constraints

- Toolchain dipin `1.99.1` di `rust-toolchain.toml` dan sama di Dockerfile; `Cargo.lock` di-commit; edition `2024` di semua crate.
- `loco-rs` `default-features = false`; tidak ada `db-sqlite`, `worker_redis`, JWT. Tanpa Redis di mana pun.
- Tanpa Node dan tanpa bundler. JS/CSS pihak ketiga di-vendor dengan versi di nama file/folder.
- CSP: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'none'`. Tidak ada inline script, `onclick`, atau `hx-on`.
- Semua teks user lewat Fluent `assets/i18n/id/main.ftl`; UI bahasa Indonesia; tanpa dark mode (token `.dark` tidak dibuat).
- `clippy -D warnings`, `unwrap_used`/`expect_used = "deny"` (boleh di tests).
- Setiap dependency di `Cargo.toml` punya komentar satu baris.
- Nama database: `agentgate_dev`, `agentgate_test` (checkout utama); `agentgate_dev_<id>`, `agentgate_test_<id>` (worktree). Port pilihan checkout utama 5150.
- Nama Compose project berawalan `agentgate-rs` — Docker host sudah berisi image/volume `agentgate_*` dari percobaan lama yang tidak boleh disentuh.
- Package crate: `agentgate-server` (bin `agentgate-server`), `agentgate-cli` (bin `agentgate`), `agentgate-core`, `agentgate-graph`.
- Belum ada remote git: script yang butuh `origin` harus jalan dengan branch lokal bila remote tidak ada.

## Review Focus

1. **Host tanpa Rust** — `bin/dev`, `bin/test`, `bin/loco`, `bin/ci` dijalankan di host yang hanya punya Docker; perintah harus jalan dan file hasil build tidak dimiliki root (cek `stat -c %U target` = user host) → tes di Task 2.
2. **Request `DELETE`/`PUT`/`PATCH` lintas origin** — CSRF juga harus menolak method selain POST, bukan hanya POST → tes di Task 5.
3. **Respons error via HTMX** — 404 untuk request boosted harus berupa halaman HTML lengkap dengan layout, bukan teks mentah → tes di Task 4.
4. **`DATABASE_URL` tidak di-set** — menjalankan server tanpa wrapper harus gagal boot, bukan memakai database default → tes kontrak config di Task 3.
5. **Nama branch worktree ekstrem** (`feature/a` vs `feature-a`, >38 karakter, `staging`) — `bin/worktree-id` menolak bentrokan dan nama terlarang → tes di Task 7.
