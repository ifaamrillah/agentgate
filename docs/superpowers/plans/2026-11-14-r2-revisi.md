# R2 Revisi — Git App, clone server, embedding, PR knowledge, tag rilis

Sumber: `docs/REVIEW-AKHIR.md` §3.0 baris **R2** (keputusan pemilik 2026-11-14). Branch
`feature/r2-revisi` dari `staging`. TDD, tes tertarget selama kerja; suite penuh + `bin/ci` sebelum merge.

## Urutan kerja

1. **GitHub App** (dasar untuk butir lain: semua panggilan provider lewat `provider_for` async).
2. **Tag rilis** (operasi provider baru: ref branch, buat ref tag).
3. **PR knowledge** (operasi provider baru: buat branch, tulis file lewat Contents API, buka PR).
4. **Clone dangkal server** untuk code graph + statistik git, tarball sebagai cadangan.
5. **Embedding lokal** fastembed-rs + pgvector, pencarian hibrid UI + MCP, benchmark.
6. Dokumen (`docs/admin/github-app.md`, benchmark, PROGRESS, REVIEW-AKHIR), visual check, `bin/ci`, merge.

## 1. GitHub App

- Settings `git.app`: `app_id`, `slug`, `client_id`, `client_secret`, `private_key` (PEM, env
  `GITHUB_APP_PRIVATE_KEY`), `webhook_secret`. Kosong = App tidak tersedia (opsi App di UI non-aktif
  dengan penjelasan). Divalidasi saat boot (PEM bisa dibaca bila diisi).
- JWT RS256 (`ring`, sudah ada di dependency tree lewat rustls): `iat = now-60`, `exp = now+540`,
  `iss = app_id`. Token instalasi `POST /app/installations/{id}/access_tokens`, di-cache per proses
  sampai 5 menit sebelum `expires_at`.
- Migrasi: `git_connections.auth` (`token|app`), `installation_id`, `app_account`, `app_permissions`
  (jsonb), `app_repo_selection`, `app_repos` (jsonb daftar full_name), `suspended_at`.
- Alur install: `POST /w/{slug}/settings/git/app/install` → state bertanda tangan HMAC (workspace,
  user, kedaluwarsa 10 menit) → `{web}/apps/{slug}/installations/new?state=…`. Setup URL global
  `GET /git/github-app/callback?installation_id&code&state`: verifikasi state + user sesi + izin
  `ManageIntegrations`, tukar `code` (OAuth user-to-server) lalu pastikan installation ada di
  `GET /user/installations` (cegah menautkan instalasi orang lain), ambil instalasi + repo dengan
  JWT/token instalasi, simpan koneksi `auth=app`.
- Repo: tautan repo App tidak memasang webhook per repo; status webhook = "Lewat App" bila repo
  ada di `app_repos`, "Belum diberi akses" bila tidak.
- Webhook App: `POST /webhooks/github-app` dengan secret App. `installation` (created/deleted/
  suspend/unsuspend/new_permissions_accepted), `installation_repositories` (added/removed),
  `pull_request`, `check_run`, `check_suite`, `status`, `push` (branch utama → index ulang graph
  bila sudah pernah di-index). Penanganan PR/CI dipakai bersama dengan webhook PAT.
- UI Cloud → GitHub: dialog Hubungkan berisi dua pilihan: **GitHub App (disarankan)** dan
  **Personal access token**. Koneksi App menampilkan akun, izin, jumlah repo, tombol Kelola di
  GitHub / Segarkan / Putuskan. GHES tetap PAT.
- Tes: server GitHub palsu menerima JWT (diverifikasi dengan kunci publik dari kunci RSA tes),
  token instalasi, OAuth code, daftar instalasi user, daftar repo instalasi.

## 2. Tag rilis

- `GitProvider::branch_head(full, branch) -> sha`, `create_tag(full, tag, sha)` (ref ringan
  `refs/tags/<nama>`; 422 "already exists" = sudah ada → dilaporkan).
- Dialog "Rilis sekarang": target commit **HEAD branch utama** (default) atau SHA tertentu, nama
  tag default = nama rilis. Setelah rilis tersimpan, tag dibuat per repo tertaut project.
  Kolom `releases.git_tags` (jsonb: repo, tag, sha, url, error). Provider tidak tertaut → rilis
  tetap sukses + flash peringatan.

## 3. PR knowledge

- Setelah usulan di-approve: worker `KnowledgePrWorker` (tidak memblokir request) menulis
  `.agentgate/knowledge/<slug>.md` (format sama dengan CLI, dipindah ke `core::knowledge`) di
  branch `agentgate/knowledge-<slug>` dari HEAD branch utama repo knowledge project (repo tertaut
  pertama), lalu membuka PR (atau menambah commit ke PR yang masih terbuka untuk dokumen yang sama).
- Penjaga: branch wajib berawalan `agentgate/knowledge-` dan tidak sama dengan branch utama.
- Tabel `knowledge_prs` (doc, repo, branch, versi, `pull_request_id`, status `queued|open|failed`,
  error). Status PR dibaca dari `pull_requests` (diperbarui webhook). Panel dokumen menampilkan PR.
- `agentgate knowledge sync` tidak berubah.

## 4. Clone dangkal server

- Settings `graph.clone`: `enabled` (true), `cache_dir`, `history_months` (12), `max_size_mb`
  (1024), `timeout_seconds` (600), `min_free_mb` (2048), `base_url` (opsional, tes: `file://`).
- `git init` + `git fetch --shallow-since=<tanggal> origin <branch>` lalu `reset --hard`.
  Kredensial lewat `GIT_CONFIG_COUNT/KEY/VALUE` (`http.extraHeader` Basic `x-access-token:<token>`)
  di env proses, tidak di argv, tidak di `.git/config`, tidak di log (stderr disensor).
- Statistik git (`history::parse`) dihitung dari clone. Gagal clone (git tidak ada, timeout,
  ukuran, disk) → tarball (statistik lama dipertahankan) + catatan sumber di status index.
- Batas ukuran (du direktori), timeout (kill), ruang disk minimum (`df`), pembersihan repo yatim
  di cleanup harian. `git` dipasang di image prod (image dev sudah punya).

## 5. Embedding

- Model default **multilingual-e5-small** (384 dimensi, ±118 M parameter). Alasan: query user
  sering bahasa Indonesia sementara kode berbahasa Inggris; model kecil, CPU, kualitas retrieval
  baik. Bisa diganti lewat config (mis. `bge-small-en-v1.5`).
- Feature Cargo `semantic` (fastembed 7.7, ONNX Runtime). Provider `fake` (hash token → vektor)
  untuk tes dan build tanpa feature. Config `graph.embedding.enabled`.
- Model diunduh ke `cache_dir` saat start proses (task latar) atau `bin/loco task embed_model`,
  tidak pernah di request; query sebelum model siap → leksikal + catatan.
- Tabel `graph_embeddings (repo_id, model, hash, embedding vector)`; `graph_symbols.embed_hash`.
  Teks = jenis + nama + signature + doc + 20 baris kode. Inkremental: hanya hash baru yang
  di-embed, hash yatim dihapus. Worker setelah index (CLI dan server).
- Pencarian hibrid: RRF (k=60) dari hasil leksikal dan semantik (cosine `<=>`). UI Cari simbol:
  sakelar mode (Hibrid/Leksikal/Semantik). MCP `ag_search` parameter `mode`.
- Benchmark `docs/benchmarks/2026-11-14-embedding.md`: waktu index, latensi query, dampak build.
