# M10 Visual Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan
> task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal (spec "Selesai bila"):** aktivitas runner tampil live di AI Office, graph bisa di-zoom sampai
fungsi. Cakupan baris M10: graph viewer, kantor isometrik, preview mockup di domain sandbox, halaman
Penghemat Token. Utang yang ditutup: tab "Viewer" code graph (M7), dokumen sebagai node graph (M7).

**Spec:** `docs/spec.md` §"Code graph" (Graph viewer), §"AI Office", §"Penghemat token", §"Persona"
(UI mockup), §"Keamanan" (Mockup HTML di iframe sandbox domain terpisah), baris M10. Prototype:
`screens-office.js` (A1 · Isometrik vektor lembut, kanvas geser/zoom + mini-map),
`screens-m7-m8-m10.js` (Graph viewer, Penghemat token, Pratinjau mockup HTML).

## Keputusan desain

- **AI Office tanpa PixiJS.** Prototype A1 yang dipilih pemilik digambar dengan Canvas 2D vanilla;
  mesinnya di-port apa adanya (gaya A1 saja) ke `static/js/office-engine.mjs` dan dimuat lazy oleh
  `static/js/office.js` hanya di halaman AI Office. PixiJS (±500 KB) tidak dibutuhkan untuk adegan
  statis + karakter; spec yang menyebut PixiJS dicatat sebagai keputusan sementara.
- **Denah parametris.** Prototype punya 3 ruangan project tetap. Kode asli: kolom selebar 17 ubin
  per dua project (ruangan belakang 17×11 dengan 2 pod × 4 meja + titik berdiri, ruangan depan 17×9
  dengan pod yang sama menghadap lorong), lorong 2 ubin, kolom terakhir = Ruang rapat (atas) +
  Pantry (bawah). Slot depan yang kosong menjadi Lounge (dekor). Project diurutkan dari yang paling
  ramai. Satu kantor per workspace, satu ruangan per project yang boleh dibuka user.
- **Karakter = data nyata** (`services::office::state`, JSON `GET /w/{slug}/office/state`, dipolling
  3 detik; GET murni):
  - job terbuka mode `auto` (claimed/running) → persona "Bekerja" di ruangan project-nya;
    `paused`/`quota` → "Dijeda"; mode `interactive` running → Ruang rapat ("Brainstorming") bersama
    pemilik runner.
  - tiket `stage_state = review` dengan job sukses di stage itu → persona "Butuh approval" (gelembung
    melayang); `decision` → "Butuh keputusan" (tanda merah berdenyut); izin aksi `pending` → "Butuh
    approval" dengan teks izin.
  - persona tanpa pekerjaan → Pantry ("Menganggur").
  - manusia = pemilik runner online (`last_seen_at` ≤ 2 menit) dengan job terbuka, duduk di ruangan
    project tempat job-nya paling banyak (spec).
  - Pekerjaan di project yang tidak boleh dibuka user tidak pernah dikirim.
- **Klik karakter** → panel samping server-side (`GET /w/{slug}/office/panel?c=<id>`, HTMX) berisi
  status, tiket, stage, runner, progres langkah, log job live (`log_view`, polling 2 detik seperti
  halaman job), aksi: Approve/Reject (form ke endpoint stage yang sudah ada, `return_to` kembali ke
  office), Keputusan → tiket, Lihat job, Kustom karakter. Tanpa JS: halaman tetap berisi panel
  ringkasan (Perlu tindakan, Runner, Aktivitas terbaru).
- **Kustom karakter** (`office_looks`, per workspace): nama tampilan, warna baju (palet 18 + custom),
  aksesori (7 pilihan), untuk manusia juga kulit/rambut/gaya rambut. Persona: hak
  `manage_ticket_settings` (sama dengan kelola persona); manusia: dirinya sendiri atau Admin.
- **Graph viewer server-side.** Tidak perlu library graf: layout berlapis (rank longest-path, urut
  barycenter) dihitung Rust (`services::graph::viewer`), dirender SVG di template; `graph-viewer.js`
  (kecil, ±4 KB, dimuat di semua halaman lewat daftar JS base tapi hanya aktif di `[data-gv]`)
  memberi geser/zoom roda, klik ganda zoom masuk, `/` fokus cari. Level: Project (repo + layanan
  lintas repo + dokumen knowledge) → Repo (modul) → Modul (file) → File (simbol + tetangga luar file)
  → Fungsi (pemanggil, dipanggil, rute lintas repo). Maks. 40 node per level (derajat tertinggi),
  sisanya diringkas "+N lainnya".
- **Layer node** ditebak dari path/jenis: UI, Logika, API, Data, Test, Eksternal, Dokumen. Filter
  layer/bahasa = query string (GET), tanpa JS.
- **Sorot tiket** = file yang diubah job tiket itu. Runner melaporkan `changed_files` (git diff
  `--name-only` base…HEAD per repo) di `FinishReport`; disimpan di `jobs.changed_files`.
- **Analisis dampak** di viewer = penutupan pemanggil (BFS terbalik) di level aktif.
- **Mockup** = artifact bernama `*.html` (persona UI/UX menyimpannya lewat `ag_artifact`). Halaman
  `/w/{slug}/t/{code}/mockup/{artifact}`: Web/Mobile, versi, screenshot otomatis (evidence screenshot
  stage), Bandingkan dengan QA (mockup vs screenshot QA berdampingan), Approve/Minta revisi lewat
  approve/reject stage yang sudah ada.
- **Domain sandbox.** `settings.preview_base_url` (dev `http://preview.localhost:<PORT>`). Layer host
  (`controllers::middleware::preview_host`): request ber-Host preview hanya boleh `GET
  /preview/{token}`, semua path lain 404; host aplikasi tidak melayani `/preview/*`. Token = id versi
  artifact + kedaluwarsa (1 jam), ditandatangani HMAC-SHA256 (kunci turunan `encryption_key`). Respons
  mockup: CSP sendiri `sandbox allow-scripts allow-forms allow-popups; default-src 'none';
  script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: https:; font-src data:
  https:; frame-ancestors <app origin>`, tanpa cookie. Iframe: `sandbox="allow-scripts"`,
  `referrerpolicy="no-referrer"`. CSP aplikasi: `frame-src <preview origin>`.
- **Penghemat token** (`/w/{slug}/p/{KEY}/settings/tokens/{ringkasan|fitur|tiket|job}`, menu
  Pengaturan project): pemakaian dari client (Claude Code `result.usage` + `total_cost_usd` →
  `jobs.tokens_input/output/cache_read/cache_write/cost_usd_micros`). Biaya tampil USD (yang
  dilaporkan client); kurs Rupiah menunggu pemilik. Penghematan terukur dicatat per kejadian
  (`token_savings`): `ag_snippet` (isi file utuh − potongan), `ag_search`/`ag_trace`/`ag_impact`
  (file yang tidak perlu dibaca), respons berlapis `ag_context`/`ag_artifact` (isi yang tidak
  dikirim), aturan lewat MCP (aturan stage lain yang tidak dikirim). RTK dan prefix stabil tidak
  terukur server → tampil "tidak terukur". Toggle per project hanya untuk fitur opsional (Gaya
  ringkas, Model per persona; `projects.token_saver`); fitur wajib terkunci aktif.
- **Token ≈ byte/4** (perkiraan kasar yang sama dengan estimasi scan knowledge M8).

## Architecture

- **Migrasi M10**: `jobs` + kolom usage + `changed_files jsonb`; `token_savings`; `office_looks`;
  `projects.token_saver jsonb`.
- **core**: `FinishReport.usage` (`TokenUsage`), `FinishReport.changed_files` (`ChangedFile`).
- **cli**: parser Claude mengisi usage rinci; runner menghitung file berubah saat selesai.
- **server**: `services::office`, `services::graph::viewer`, `services::tokens`, `services::mockups`
  (token preview), `controllers::{office, preview, tokens}`, middleware `preview_host`, view
  `views::{office, graph_viewer, tokens}`.
- **UI**: sidebar "AI Office"; tab Code graph "Viewer" aktif; Pengaturan project "Penghemat token";
  tautan "Pratinjau mockup" di artifact `.html`.

## Global Constraints

- Aturan M1–M9 tetap (UUID v7, `timestamptz`, enum text + CHECK + tes, 404 lintas workspace, PRG,
  Fluent "Anda", tanpa inline script, CSP `script-src 'self'`, GET tidak menulis).
- Tes tidak memanggil jaringan. Komponen baru masuk `/_dev/ui` + design-system.md.
