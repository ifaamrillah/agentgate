# R5: AI Office baru (V1 Isometrik + Denah + cahaya hangat) — rencana

Keputusan pemilik (`docs/REVIEW-AKHIR.md` §3.0, baris AI Office): kanvas Canvas 2D M10 diganti
**V1 Isometrik Studio** dengan tombol beralih ke **Denah (V2)** dan **pencahayaan hangat V3**,
dibangun dengan **SVG + vanilla JS**. Acuan visual: `docs/reference/ui-prototype/office-v1/`.

## Batas

- Server tidak berubah kecuali yang dibutuhkan halaman (atribut `data-me` untuk kunci localStorage,
  SVG pratinjau menggantikan `<canvas>`). JSON `/office/state`, panel, approve/reject, looks tetap.
- Semua fungsi M10 tetap: ruangan per project + Ruang rapat + Pantry (+ Lounge pengisi slot),
  karakter dari job/persona/tiket/runner online (90 dtk), geser/zoom/pinch/keyboard, mini-map,
  tab ruangan, panel detail (log live, Approve `success`/Reject `danger`, dialog Kustom teraudit),
  polling 3 dtk.

## Arsitektur

| Berkas | Isi |
|---|---|
| `static/js/office-core.mjs` | Logika murni tanpa DOM: status → tampilan, tata letak ruangan (grid kolom × depan/belakang), kursi per jenis ruangan, penempatan karakter stabil, penghindaran tumpukan label, LOD zoom, matematika kamera, kunci mode per user. Diuji `node --test`. |
| `static/js/office-svg.mjs` | Helper SVG + karakter chibi (aksesori, gaya rambut, hijab) + renderer Isometrik dan Denah. Warna lewat `var(--of-*)`, jadi tema gelap tanpa gambar ulang. |
| `static/js/office-engine.mjs` | `mount()` (API sama dengan M10 + `mode()`): kamera SVG, input pointer/pinch/wheel/keyboard, label HTML, mini-map `<use>`, rebuild per ruangan saat isi berubah. `preview(svg, ch)` untuk panel/dialog. |
| `static/js/office.js` | Lem halaman: polling, panel, tab, zoom, toggle Isometrik/Denah (localStorage `ag-office-view:<pid>`). |
| `css/components/office.css` | Token adegan terang/gelap, animasi (hanya `prefers-reduced-motion: no-preference`), label, LOD jauh. |
