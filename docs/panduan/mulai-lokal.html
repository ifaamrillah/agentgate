Memasang Agent Gate di project Anda

Server Agent Gate berjalan di laptop Anda sendiri, jadi semua alamat di panduan ini memakai http://localhost:5150. Ikuti langkahnya berurutan, dari menyalakan server sampai agent mengerjakan tiket pertama.

Yang perlu disiapkan

  • Docker (Compose v2), git, dan curl di laptop.
  • Satu repo git untuk dipasangi Agent Gate. Repo baru kosong juga bisa.
  • Minimal satu client AI yang sudah login: Claude Code, Codex, Antigravity CLI (agy), Cursor, OpenCode, atau Copilot CLI.
  • Source Agent Gate di ~/SEVIMA/Private/agentgate. Folder ini disebut folder Agent Gate di bawah.
1

Nyalakan server

Di folder Agent Gate, jalankan server development. Biarkan terminal ini terbuka.

cd ~/SEVIMA/Private/agentgate
bin/dev

Server siap di http://localhost:5150. Di terminal kedua, isi data contoh supaya ada akun dan project untuk dicoba:

bin/loco db seed

Seed membuat workspace PT Contoh dengan project KSR (Kasir Online) dan lima akun, antara lain owner@agentgate.test dan dev@agentgate.test. Semua akun itu tanpa password.

2

Masuk ke web

Cara cepat: pakai akun contoh. Cetak link masuk sekali pakai:

bin/loco task dev_login email:owner@agentgate.test

Buka link http://localhost:5150/_dev/login?token=... yang tercetak di browser. Link berlaku 10 menit dan setara password, jadi jangan dibagikan atau di-commit.

Cara lengkap: daftar sendiri di http://localhost:5150/register. Email verifikasi tidak dikirim ke inbox sungguhan. Semua email lokal masuk ke Mailpit di http://localhost:8025, jadi buka di sana untuk mengklik link verifikasi.

Tombol masuk dengan Google dan GitHub baru aktif kalau GOOGLE_CLIENT_ID atau GITHUB_CLIENT_ID diisi. Secara lokal, pakai dua cara di atas.

3

Siapkan workspace dan project

Kalau memakai data seed, workspace pt-contoh dan project KSR sudah ada. Lewati langkah ini dan pakai KSR di langkah berikutnya.

Untuk project baru milik Anda:

  1. Buat workspace, lalu undang tim lewat Pengaturan → Anggota (opsional).
  2. Buat project dengan kode pendek, misalnya DEMO, lalu pilih workflow.
  3. Hubungan repo GitHub (Pengaturan project → Git) hanya perlu untuk fitur PR. Untuk percobaan awal, boleh dilewati.
4

Pasang CLI agentgate

Di server lokal, perintah curl .../install.sh | sh tidak tersedia (hasilnya 404), karena belum ada rilis CLI yang dikonfigurasi. Di lokal, CLI dibangun dari source. Langkah ini hanya perlu diulang kalau kode CLI berubah.
cd ~/SEVIMA/Private/agentgate
bin/sh cargo build -p agentgate-cli
bin/sh cp target/debug/agentgate /workspace/tmp/agentgate
mkdir -p ~/.local/bin
install -m755 tmp/agentgate ~/.local/bin/agentgate

Pastikan ~/.local/bin ada di PATH, lalu cek hasilnya:

agentgate --version
agentgate doctor

agentgate doctor memeriksa git, client AI yang terpasang, dan koneksi server. Client AI yang belum terpasang ditandai opsional. Yang wajib hanya satu client dan login.

5

Login CLI ke server lokal

Login lewat kode perangkat. Sebelumnya, pastikan browser Anda sudah masuk ke web (langkah 2).

agentgate login --server http://localhost:5150

Terminal menampilkan kode dan link konfirmasi. Buka link itu di browser, setujui, lalu kembali ke terminal. Cek hasilnya dengan agentgate status.

6

Pasang Agent Gate di repo Anda

Masuk ke repo yang ingin dipasangi. Kalau repo baru, siapkan dulu dengan satu commit kosong:

mkdir ~/proyek-baru && cd ~/proyek-baru
git init
git commit --allow-empty -m "init"

Lalu pasang aturan Agent Gate, dengan kode project dari langkah 3:

agentgate init --project KSR

Perintah ini:

  • menulis file aturan, MCP, dan hook untuk client AI, antara lain AGENTS.md, CLAUDE.md, .mcp.json, .claude/settings.json, .codex/, .cursor/, .agents/, dan opencode.json;
  • mencadangkan aturan lama repo ke .agentgate/backup/ sebelum menimpanya;
  • membuat satu commit bernama chore: pasang aturan Agent Gate.

Pastikan tidak ada file yang sedang di-stage. Kalau ada, init berhenti dan meminta Anda merapikannya dulu.

7

Hubungkan client AI ke MCP server

Di web, buka Akun → Hubungkan client AI. URL MCP lokal adalah:

http://localhost:5150/mcp

Saat client AI pertama kali memakai server agentgate, ia membuka browser untuk login lewat OAuth. Untuk Claude Code, file .mcp.json dari langkah 6 sudah memuatnya. Untuk Antigravity CLI, jalankan agy sekali secara interaktif supaya login Google dan trust folder repo selesai, lalu login server agentgate lewat /mcp.

8

Nyalakan runner

Di folder repo, jalankan runner dan biarkan terminal terbuka. Runner adalah bagian yang menjalankan agent di laptop Anda.

cd ~/proyek-baru
agentgate runner start

Opsi berguna: --client claude memilih client AI, dan --once membuat runner berhenti setelah satu job selesai.

9

Coba dengan tiket pertama

  1. Buka board project di http://localhost:5150/w/pt-contoh/p/KSR (ganti KSR dengan kode project Anda).
  2. Buat tiket dan geser ke stage yang dikerjakan agent.
  3. Job muncul di terminal runner dan agent mulai bekerja.
  4. Hasilnya (diff, PR, evidence tes) kembali ke tiket untuk Anda review.

Perintah sehari-hari

PerintahFungsi
agentgate statusAkun, runner, dan status aturan di repo ini
agentgate doctorCek kesiapan perangkat
agentgate rules checkBandingkan aturan repo dengan versi server
agentgate knowledge pullTarik dokumen knowledge project ke .agentgate/knowledge/
